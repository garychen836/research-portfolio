# Research portfolio: Gary Chen

A single-page research portfolio (AI tools for research, qualitative and mixed-methods case studies, publications).

- `index.html` is the whole site: static HTML, CSS and a little JavaScript, with no build step and no dependencies.
- Preview locally: `python3 -m http.server 8765`, then open http://localhost:8765
- Hosting: GitHub Pages from the `main` branch, root folder (`.nojekyll` keeps Pages from processing the files).

Client and company names in the case studies are removed or generalized.
